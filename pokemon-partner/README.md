# 🌊 포켓몬 파도타기 파트너

포켓몬 기술 **"파도타기(Surf)"**와 충동 파도타기(Urge Surfing)를 잇는 개인 팬메이드 회복 일지.
`index.html` 한 파일로 동작하며, 기록은 내 브라우저(localStorage)에만 저장된다.

## 기능
- **파트너 고르기** — 잉어킹 · 꼬부기 · 이브이 · 피츄 · 라프라스
- **같이 파도타기** — VAS(0~10) 사전/사후 체크 + 3·5·10분 타이머, 파트너가 파도 위에서 함께 버틴다
- **오늘 하루** — "도박하지 않았어요" 체크인 / "미끄러졌어요" 기록
- **진화** — 누적 친밀도가 정해진 기준을 넘으면 진화 (예: 잉어킹 → 갸라도스 @200)

## 설계 원칙 (도박 회복을 위한 의도적 선택)
- **뽑기·확률·랜덤 보상 없음** — 가챠, 이로치 확률, 랜덤 인카운터처럼 도박 회로를 건드리는 요소를 넣지 않는다. 모든 보상은 고정값.
- **친밀도는 절대 줄지 않음** — 미끄러진 날도 처벌하지 않는다(금단위반효과 방지). 스트릭 리셋 없음.
- **안전장치** — 하단에 1336·109 상시 노출, 사후 VAS ≥ 9 또는 미끄러짐 기록 시 1336 강조 (`agents/clinical-safety.md` §4.2).

## 실행
브라우저로 `index.html`을 열면 끝.
