# 🃏 포켓몬 카드 팩 도감

포켓몬을 고르면 **그 포켓몬 카드가 나오는 팩**, **팩 1개 적정 가격(영문·일본·한국판)**, **수록 카드와 가장 비싼 카드**를 보여주고,
개봉 의사를 확인한 뒤 **가상으로 팩을 개봉**해보는 개인 팬메이드 앱. `index.html` 한 파일로 동작한다.

## 흐름
1. **포켓몬으로 찾기**: 한국어·영어·일본어 이름으로 검색하면 영문판 카드를 비싼 순으로 보여준다.
2. **카드 상세**: 영문판 시세(TCGplayer USD·Cardmarket EUR를 원화로 환산), 일본판·한국판 시세 검색 링크와 직접 입력, 수록 팩, 한 팩에서 나올 확률, 팩으로 뽑을 때 평균 비용과 싱글 구매가 비교.
3. **팩 정보**: 영문 정가와 일본·한국판 대응 팩 정가, 내가 본 시세 입력, 한 팩의 평균 가치, 가장 비싼 카드 TOP 10, 레어도별 확률, 수록 카드 전체.
4. **개봉**: "개봉할까요?" 확인 → 팩 뜯기 → 한 장씩 뒤집기(레어도별 이펙트, 레어 슬롯은 맨 뒤) → 결과 요약과 최고가 카드.
5. **내 바인더**: 가상으로 뽑은 카드 모음과 누적 기록("실제로 샀다면 ₩X · 실제 지출 ₩0"), 스캔한 실물 카드 컬렉션과 총 시세.
6. **📷 카드 스캔**: 신분증 스캔처럼 카드 모양 틀에 맞추면 네 변이 초록색으로 잡히고, 흔들림이 멈추면 자동 촬영한다.
   OCR로 이름과 카드 번호(예: `199/165`)를 읽어 카드를 찾고, 이벤트 모달에서 가격을 **쪼아서** 공개한다.
   - 레어도 발표 → 몬스터볼 덮개를 천천히 밀어 올리면 가격이 아래부터 조금씩 보인다(진동·심장박동 효과음).
   - 72% 넘게 올리면 공개되고, 덜 올리고 놓으면 덮개가 다시 내려온다.
   - 시세 구간별 연출: 5천 원 미만 / 3만 원 미만 / 10만 원 미만 "✨ 대박!" / 그 이상 "👑 잭팟!!" (컨페티·팡파르·진동 세기가 커진다)

### 스캔 팁과 제약
- 카메라는 **https 또는 localhost**에서만 켜진다. 휴대폰에서 쓰려면 GitHub Pages 같은 곳에 올리거나, 🖼️ 사진에서 불러오기(카메라 앱으로 촬영)를 쓴다.
- 어두운 바닥, 반사 없는 조명에서 잘 잡힌다. 카드 번호가 가장 중요한 단서다.
- OCR은 영어 모델([Tesseract.js](https://github.com/naptha/tesseract.js))이라 **영문판 카드 기준**. 일본·한국판 카드도 번호는 읽지만 영문판과 번호 체계가 달라 다른 카드가 나올 수 있다(후보 중에서 고르면 된다).
- OCR 엔진(약 5MB)은 첫 스캔 때 한 번 내려받는다.
